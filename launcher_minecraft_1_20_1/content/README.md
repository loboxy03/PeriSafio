# Contenido distribuido por PeriSafio Launcher

El launcher espera encontrar aquí:

- `mods/` — mods de Forge 1.20.1.
- `resourcepacks/` — resource packs.
- `config/` — configuración de mods, incluyendo FancyMenu.

Los archivos binarios del paquete original (JAR y ZIP) todavía deben subirse a GitHub. El resource pack grande de Dedsafio 4 supera por sí solo el límite de 100 MB por archivo que GitHub impone a los archivos normales del repositorio; para distribuirlo se necesita Git LFS o publicarlo como un archivo descargable externo y adaptar el manifiesto/servidor de actualizaciones.
