# Resource packs

Coloca aquí los archivos `.zip` que debe recibir el jugador. El administrador del launcher genera el manifiesto a partir de estos archivos.

Aviso: GitHub bloquea los archivos normales de repositorio de más de 100 MB. El resource pack Dedsafio 4 incluido en el paquete fuente original supera ese límite, así que necesita Git LFS o alojamiento externo antes de distribuirlo desde el launcher.
