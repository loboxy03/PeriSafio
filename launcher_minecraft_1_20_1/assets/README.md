# Assets del launcher

Esta carpeta debe contener los archivos binarios originales del proyecto:

- `launcher.ico` — icono requerido por `build_windows.bat` y el instalador Inno Setup.
- `launcher_bg.jpg` — fondo del launcher.
- `perisafio_dashboard_reference.png` — referencia visual del panel.
- `perisafio_logo.png` — logotipo.

Los archivos binarios originales están en el paquete fuente completo, pero GitHub no puede recibirlos a través del método de edición de archivos de texto usado en este cambio. No se deben reemplazar por archivos vacíos: hay que subir los archivos reales para que el launcher conserve su diseño y pueda compilarse.
